Ratio Memorization Guide for Drawing

This page introduces a teaser row of anchor ratios followed by three levels of visual ratio memorization from 1:2 to 1:1. All ratios are written as short side : long side, so rotation does not change the answer. The square button beside each row toggles blue dashed square-grid subdivisions.

Suggested use: scan the teaser first to build anchor points, memorize Level 1 next, use Level 2 for daily drawing practice, and use Level 3 only when you want finer visual calibration. The goal is not mathematical perfection, but stable visual judgment.
